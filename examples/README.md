# Example outputs

These are new reference simulations using the parameters in [PUBLICATION_PARAMETERS.md](../PUBLICATION_PARAMETERS.md), not the original manuscript data or figures. The PNG and PDF files in `figures/` were generated with the supplied Python code (including the updated Figure 2 energy-axis limits).

- [Figure 1 (PDF)](figures/figure_1.pdf) — single-atom ESD.
- [Figure 2 (PDF)](figures/figure_2.pdf) — two-atom ESD, K=600 and K=10000.

Each case directory contains `parameters.json` (actual settings and jump count), `empirical.csv` (trait positions and masses at snapshot times), `deterministic.csv` (grid and densities at snapshot times), and `energy.csv` (energy, mass and diversity time series). The complete intermediate deterministic density arrays in `results.npz` are not bundled to keep the GitHub upload small; they are generated by `simulate.py` when rerun.
